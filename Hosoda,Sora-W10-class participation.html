1 Introduction

Today’s class covered project updates, data preparation, analysis planning, statistical methods, BigQuery, and the Week 11 assignments.

2 Project Updates

The post-proposal activity should explain:

  • Analytics objectives
  • Research methods
  • Data availability
  • Feasibility of the analysis
  • Confirmation from the faculty lead

Survey data can be planned before collection because researchers control the questions and measurements. Secondary data may take longer because researchers must confirm that the necessary variables are available.

3 Data Preparation and Wrangling

Data preparation and data wrangling have similar meanings. Wrangling is often used for secondary data because it may require more changes.

The process may include:

  • Importing data
  • Correcting labels
  • Handling missing values
  • Reverse coding
  • Joining datasets
  • Creating new variables

After cleaning the data, it should be saved as a new .sav file. This allows researchers to use the cleaned data without repeating the process.

4 Data Dictionary and Labels

A data dictionary includes:

  • Variable names
  • Variable labels
  • Value labels
  • Missing values
  • Measurement scales

The view_df() function from the sjPlot package can create a data dictionary. Missing or incorrect labels should be corrected using the questionnaire and coding instructions.

In Case 31, Q8 should be labeled as the loan rate.

5 Reverse Coding and Multi-Item Measures

Reverse-coded variables should always be checked after they are created.

The employee proficiency items had acceptable reliability and could be averaged into an index. The operational effectiveness items did not have sufficient reliability, so they should be analyzed separately.

6 BigQuery and GA4

BigQuery is part of Google Cloud and can store and analyze large datasets such as GA4 data.

The basic process includes:

  1. Create a Google Cloud project
  2. Set up billing
  3. Open BigQuery
  4. Connect GA4 to BigQuery
  5. Find the project ID
  6. Access the data from R

R packages can connect to BigQuery through an API, so researchers do not need to download the entire dataset.

7 Data Analysis Planning Table

For each analytics objective, research question, or hypothesis, the table should identify:

  • Constructs and their roles
  • Variables
  • Operationalization
  • Measurement scales
  • Descriptive statistics
  • Inferential statistics

The dependent variable is used first to decide which statistical method is appropriate.

8 Selecting Statistical Methods

Parametric tests are generally used for interval or ratio dependent variables. Nonparametric tests are used for ordinal or nominal dependent variables.

Likert-type scales are technically ordinal, but researchers often treat them as interval scales to calculate means and use parametric tests.

9 T-Tests and ANOVA

A one-sample t-test compares one group with a reference value.

An independent-samples t-test compares the means of two independent groups. In Case 31, it can compare employee proficiency between members living in and outside the headquarters area.

ANOVA is used when there are more than two groups.

10 Cross-Tabulation and Chi-Square

Cross-tabulation is used for categorical variables.

In Case 31, service awareness has three categories, while member residence has two categories. These variables can be analyzed using a two-by-three cross-tabulation and a chi-square test of independence.

A p-value below .05 suggests that the variables are associated.

11 Regression and Other Methods

Multiple regression is used when several variables predict one metric dependent variable. Other methods include:

  • Logistic regression for a binary dependent variable
  • ANCOVA for comparing groups while controlling another variable
  • MANOVA for multiple related dependent variables
  • Factor analysis for relationships among measurement items
  • Cluster analysis for identifying similar groups

12 Data Analysis Assignment

The Week 11 assignment uses Case 31 and the cleaned data from the previous assignment.

For R1, R2, R5, and R6, we should:

  1. Review descriptive statistics
  2. Identify the story in the data
  3. Conduct the appropriate statistical test
  4. Explain the insight

The report should focus on the findings rather than listing the mechanical steps of hypothesis testing. Test statistics and p-values can be placed inside parentheses.

13 Reporting Results

Tables and figures should be used to explain the findings clearly. Quarto labels can automatically create numbers:

  • Figure labels begin with fig-
  • Table labels begin with tbl-

The echo: false option can hide code when it is not necessary for the audience.
